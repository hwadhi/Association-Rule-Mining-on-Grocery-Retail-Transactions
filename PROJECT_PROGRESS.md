## Key parameters and decisions
- Seed 42 everywhere; fully deterministic (fixed ordering; curveball swaps use `sorted()` before shuffling). Only benchmark timing columns vary between runs.
- Encoding: mlxtend `TransactionEncoder`, sparse CSR -> sparse DataFrame `onehot`.
- Itemsets: **MIN_SUPPORT = 0.5% (38 baskets)** chosen from an 11-point sensitivity grid (5% ... 0.1%): 725 itemsets (101/451/173). Apriori == FP-Growth at every threshold/scale.
- Rules: 1,940 candidates; selected with **confidence >= 0.20 and lift >= 1.2** -> 562; redundancy flag = confidence improvement < 0.01 over best single-item parent (49 of 363 two-antecedent rules); naive hypergeometric test + **curveball null model (500 randomisations preserving basket sizes and item counts)** -> empirical p, BH q, excess lift (= lift / null mean lift); funnel 562 -> 562 -> 513 -> 227 (q < 0.05) -> **217** (excess lift >= 1.2).
- Central result: null lift > 1 for all 1,940 rules (median 1.49); full pipeline on 20 null data sets gives ~480 selected rules (425-523) vs 562 real; median excess lift 1.15.

## Algorithms implemented
Apriori, FP-Growth (mlxtend 0.25.0), association_rules, curveball randomisation, hypergeometric test, Benjamini-Hochberg FDR, Spearman correlation, NetworkX graph (Kamada-Kawai layout).

## Errors encountered and resolutions
1. Shell brace expansion created a literal `{data,outputs` folder -> removed, folders created explicitly.
2. Delimiter detector initially picked `;` (penalised ragged rows) -> now picks the delimiter splitting most lines; column count from the widest row of the whole file.
3. A draft "size-stratified adjusted lift" was biased (fixed-size baskets are mechanically anti-correlated) -> replaced by the curveball null model.
4. Run-to-run drift in null-model counts (set-iteration order depends on insertion history) -> `sorted()` before shuffling, deterministic row order; verified identical outputs over repeated runs.
5. Interpretation numbers written from an earlier run were re-verified and corrected after each change; timing-based statements are given as rounded ranges.
6. Stale outputs from discarded drafts were removed by deleting all generated files and re-running the notebook.
